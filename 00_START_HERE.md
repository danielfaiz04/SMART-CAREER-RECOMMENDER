## 📊 PROJECT OVERVIEW

### What It Does
Users fill out a form about their interests, skills, experience, and personality, and the application uses both machine learning and business logic rules to recommend 3 suitable careers with personalized learning roadmaps.

### How It Works
1. **User Input** → Form collects 4 data points
2. **ML Processing** → Decision Tree model makes predictions
3. **Rule Application** → 9 business rules refine recommendations
4. **Score Calculation** → Match scores generated (0-100%)
5. **Results Display** → Top 3 jobs shown with details
6. **History Tracking** → Predictions saved for later

### Technology Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Python 3.8+ with Flask 2.3.3
- **ML:** scikit-learn with Decision Tree Classifier
- **Data:** JSON files for storage
- **Deployment:** Flask development or WSGI server
