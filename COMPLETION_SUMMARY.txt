🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

Step 1: Install Dependencies
  pip install -r requirements.txt

Step 2: Train ML Model (one-time)
  cd ml
  python train_model.py

Step 3: Start Backend Server
  cd backend
  python -m flask run --host=0.0.0.0 --port=5000

Step 4: Open Frontend
  Navigate to: http://localhost:5000/frontend/index.html
  Or: Open frontend/index.html directly in browser

Step 5: Use the Application
  • Fill out the form with your preferences
  • Click "Dapatkan Rekomendasi"
  • See your career recommendations!

Step 6: Optional - Test API
  python test_api.py

📝 CUSTOMIZATION GUIDE
═══════════════════════════════════════════════════════════════════════════════

Add New Job:
  1. Edit backend/dataset.json - add new entry
  2. Edit backend/app.py - add to skill_roadmaps
  3. Retrain model: python ml/train_model.py
  4. Restart server

Change UI Colors:
  1. Edit frontend/style.css
  2. Update gradient colors (currently #667eea to #764ba2)
  3. Reload browser (no server restart needed)

Add New Rule:
  1. Edit backend/app.py function get_rule_based_recommendations()
  2. Add new if/then condition
  3. Restart server

Modify Scoring:
  1. Edit backend/app.py function calculate_match_score()
  2. Adjust weights and formulas
  3. Restart server

📞 SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Common Issues:

Port Already in Use:
  → netstat -ano | findstr :5000
  → taskkill /PID <PID> /F

Module Not Found:
  → .venv\Scripts\activate
  → pip install -r requirements.txt

Model File Missing:
  → cd ml && python train_model.py

Frontend can't reach Backend:
  → Check server is running on :5000
  → Check firewall settings
  → Check browser console (F12) for errors

Check Setup Status:
  → python verify_setup.py
