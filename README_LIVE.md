## 🎯 What is Smart Career Recommender?

A cutting-edge AI-powered career guidance application that helps users discover their ideal career paths based on:

- **Personal Interests** (Design, Marketing, Technology, etc.)
- **Current Skills** (40+ skills database)
- **Work Experience** (Beginner to Senior levels)
- **Personality Type** (Introvert, Ambivert, Extrovert)

## ✨ Key Features

### 🤖 AI-Powered Recommendations
- Machine Learning model trained on career data
- Rule-based engine for logical career matching
- Top 3 personalized career recommendations

### 📊 Smart Scoring System
- Match percentage (0-100%) for each career
- Skills gap analysis
- Learning roadmap with actionable steps

### 💾 History Tracking
- Save and review past recommendations
- Track career exploration journey
- Up to 50 historical records

### 🎨 Modern UI/UX
- Responsive design (mobile & desktop)
- Dark/Light theme support
- Indonesian language interface
- Intuitive form-based assessment

## 📖 How to Use

### Step 1: Career Assessment
1. Select your primary interest
2. Check all skills you currently have
3. Choose your experience level
4. Select your personality type

### Step 2: Get Results
- Click "Dapatkan Rekomendasi"
- Wait for AI processing (5-10 seconds)
- Review your personalized recommendations

### Step 3: Explore Options
- View match scores and explanations
- Check skills you need to learn
- Follow the suggested learning roadmap
